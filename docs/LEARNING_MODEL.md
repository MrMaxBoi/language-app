Kokoro Learning Model

Philosophy

Kokoro is skill-based rather than category-based.

Traditional systems:

* Grammar
* Vocabulary
* Travel

Kokoro:

* Use particle は correctly
* Use particle に correctly
* Form present tense verbs
* Recognize transportation vocabulary

Each skill represents something that can realistically be mastered.

Question Mapping

Every question maps to a measurable skill.

Example:

Question:
“がっこう___いきます”

Maps to:

skillId:
particle_ni_destination

This allows mastery, memory, coverage, and recommendations to operate at the skill level.

⸻

Recommendation Philosophy

Recommendations should be generated from skill state.

Example:

Instead of:

“Do more grammar”

The system should produce:

* Practice Particle に
* Review Transportation Vocabulary
* Reinforce Present Tense Verbs

This creates actionable learning guidance.
